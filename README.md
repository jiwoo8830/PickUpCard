# 나의 최종프로젝트 제안서

## 주제와 이름

- 주제: 하루 추천 카드 뽑기 사이트
- 이름: **오늘 뭐라카드라**

## 주요 사용자와 사용 상황

- 주요 사용자: 오늘 뭘 먹고 뭘 할지 고르기 귀찮은 학생·친구들
- 사용 상황: 점심 전, 쉬는 시간, 심심할 때 휴대폰이나 컴퓨터로 가볍게 열어 봄

## 해결할 문제와 목표 한 문장

- 문제: 매일 반복되는 "오늘 뭐 먹지? 뭐 하지?" 고민이 귀찮다.
- 목표 한 문장: **고르기 귀찮은 하루의 선택을, 카드 3장 뽑기로 가볍게 정해 준다.**

## 구성 방식

3페이지 (카테고리 3개 = 페이지 3개), 각 페이지에 구역 4개씩

| 페이지       | 파일          | 역할            | 사용하는 덱                    |
| ------------ | ------------- | --------------- | ------------------------------ |
| 밥 추천      | `index.html`  | 밥 카드 뽑기    | `rice` (밥 카드 8장)           |
| 조언         | `advice.html` | 조언 카드 뽑기  | `advice` (조언 카드 8장)       |
| 오늘 해볼 일 | `todo.html`   | 할 일 카드 뽑기 | `todo` (오늘 해볼 일 카드 8장) |

세 페이지의 구역 구성은 같다.

| 구역      | 역할                                          |
| --------- | --------------------------------------------- |
| 소개      | 사이트가 무엇인지 한 문장으로 설명            |
| 이용방법  | 메뉴에서 카테고리 고르기 → 뽑기 → 카드 뒤집기 |
| 뽑기      | "뽑기" 버튼 (핵심 기능 구역)                  |
| 결과 확인 | 뽑힌 카드 3장이 나타나는 영역                 |

- 모든 페이지 상단에 공통 메뉴를 넣어 3페이지를 서로 이동할 수 있게 하고, 현재 페이지는 검은색으로 표시한다.
- 페이지의 `<body data-deck="...">` 값으로 어떤 덱을 쓸지 정한다.

### 파일 구성

| 파일            | 역할                                   |
| --------------- | -------------------------------------- |
| `style.css`     | 3페이지 공통 스타일과 CSS 애니메이션   |
| `app.js`        | 3페이지 공통 JavaScript 기능 2개       |
| `cards.js`      | 카드 데이터 (밥 / 조언 / 오늘 해볼 일) |
| `images/`       | 카드 앞면 24장 + 뒷면 1장 (SVG)        |
| `gen_images.py` | 카드 이미지를 만든 스크립트            |

### 카드 구조

| 구분 | 내용                                                          |
| ---- | ------------------------------------------------------------- |
| 뒷면 | 모든 카드가 같은 공통 이미지 (`back.svg`)                     |
| 앞면 | 위쪽 이모지 이미지 약 60% + 아래쪽 제목과 한두 줄 설명 약 40% |

## 필수 콘텐츠

- 글
  - 카테고리별 카드 글 (제목 + 한두 줄 설명) 8장씩, 총 24장
  - 사이트 소개, 이용방법, 뽑기 구역 문구
- 이미지
  - 카드 뒷면 공통 이미지 1장 (`back.svg`)
  - 카드 앞면 이미지 24장: 이모지와 배경색으로 만든 SVG (`gen_images.py`로 제작)
  - 이미지 파일은 직접 찍거나 내려받은 사진이 아니라 만들어 낸 도형·이모지이므로 별도 저작권 출처가 필요 없다.
  - 이모지 모양은 사용하는 기기의 기본 글꼴에 따라 조금 다르게 보일 수 있다.
- 목적지
  - 상단 메뉴: 밥 추천 / 조언 / 오늘 해볼 일 페이지로 이동

## JavaScript 기능 2개

### 기능 1. 카드 3장 뽑기

- 사용 목적: 고르기 귀찮은 선택을 무작위로 정해 준다.
- 누를 요소: "뽑기" 버튼
- 바뀌는 내용: 현재 페이지의 덱에서 서로 다른 카드 3장이 뒷면 상태로 나타난다.
- 확인 방법: 버튼을 여러 번 눌러서 (1) 한 번에 나온 3장이 항상 서로 다른지, (2) 누를 때마다 구성이 바뀌는지, (3) 이전 카드가 지워지고 항상 3장만 보이는지 확인한다.

### 기능 2. 카드 뒤집기

- 사용 목적: 뽑은 카드의 내용을 직접 확인하는 재미를 준다.
- 누를 요소: 뽑힌 카드
- 바뀌는 내용: 뒷면 이미지에서 앞면(이미지 + 설명)으로 바뀌고, 다시 누르면 뒷면으로 돌아온다.
- 확인 방법: 카드를 눌러 앞뒤가 바뀌는지, 새로 뽑으면 다시 뒷면부터 시작하는지 확인한다.

## CSS로 넣은 효과 (JavaScript 기능이 아님)

- 카드 등장: 뽑을 때 카드가 위에서 떨어지며 나타난다.
- 뒤집힌 카드 효과: 앞면이 보일 때 빛이 번쩍이고 빛줄기가 지나간다.
- 무지개 효과: 사이트 이름의 "카드"와 구역 제목 글자, "뽑기" 버튼 배경에 색이 계속 흐른다.

## AI 활용 계획

- 기획
  - 사이트 구조와 구역 구성에 대한 의견 받기
  - 카드 글 아이디어 후보 받기 (최종 선택과 글 다듬기는 직접 한다)
- 구현
  - 뽑기·뒤집기 코드의 작동 원리를 설명 듣고, 직접 작성해 보기
  - 막히는 부분만 질문하기
  - CSS 카드 모양과 애니메이션 예시 받아서 값을 직접 바꿔 보기
  - 카드 이미지(이모지 SVG)를 만드는 스크립트 도움 받기
- 오류 해결·개선
  - 콘솔(F12)의 오류 메시지를 보여 주고 원인 물어보기
  - 완성 후 모바일 화면과 코드 정리 개선점 검토받기

## 제외할 기능과 미정 항목

### 제외할 기능

- 서버, 로그인, 결제
- 한 번에 뽑는 장수 선택 (3장 고정)
- 뽑은 기록 저장
- 카드 전체 목록 페이지·구역, 별도의 만든 이야기 페이지 (뽑기 중심으로 구성)

### 미정 항목

- 카드 글을 본인 말투로 다듬을지 (시간이 있을 때)
- 시간이 남으면 추가할 후보: 뽑기 횟수 표시, 카드 전체 목록 구역, 만든 이야기 구역

## 완성 확인 기준

- [ ] 3페이지가 메뉴로 서로 이동되고, 현재 페이지가 표시된다.
- [ ] 각 페이지에서 뽑기를 누르면 그 페이지의 덱에서 서로 다른 카드 3장이 나온다.
- [ ] 다시 뽑으면 이전 카드가 지워지고 새 3장이 나온다.
- [ ] 카드를 누르면 앞면과 뒷면이 바뀐다.
- [ ] 새로 뽑으면 카드가 다시 뒷면부터 시작한다.
- [ ] 휴대폰 화면(폭 약 375px)에서도 카드와 메뉴가 깨지지 않는다.
- [ ] 콘솔(F12)에 오류가 없다.
